# Ksenia VK Tools

**Менеджер сообщества ВКонтакте** — десктопное приложение на PyQt6 для администраторов и владельцев сообществ. Позволяет пакетно управлять участниками через официальный VK API.

> ⚠️ **Неофициальный инструмент.** Проект не связан с ВКонтакте и не одобрен VK. Используйте на свой риск.

---

## 📋 Возможности

- ✅ **Пакетное удаление участников** сообщества
- ✅ **Пропуск администраторов** — управляющие сообщества никогда не удаляются
- ✅ **Тестовый режим** — предпросмотр без реального удаления
- ✅ **Лимит за запуск** — контроль количества удалений в одной сессии
- ✅ **Настраиваемая задержка** между запросами к API
- ✅ **Остановка в любой момент** — кнопка «Остановить» прерывает процесс
- ✅ **Лог в реальном времени** — видно каждого удалённого и каждую ошибку

## 🖥️ Требования

- **Python 3.9+** (рекомендуется 3.10+)
- **PyQt6**
- **vk_api**

Установка зависимостей:

```bash
py -m pip install pyqt6 vk_api
```

> 💡 Если команда `pip` не распознаётся, используйте `py -m pip` (как показано выше). Если не распознаётся и `py` — установите Python с [python.org](https://www.python.org/downloads/), отметив галочку **«Add Python to PATH»**.

## 🚀 Быстрый старт

1. **Сохраните** файл `ksenia_vk_tools.py` в удобную папку.
2. **Запустите**:

   ```bash
   py ksenia_vk_tools.py
   ```

3. **Получите токен администратора** — см. раздел ниже.
4. **Узнайте ID сообщества** — см. раздел ниже.
5. **Сначала запустите в тестовом режиме** (галочка включена по умолчанию) — убедитесь, что список участников читается правильно.
6. **Снимите галочку** и запустите реальную очистку.

## 🔑 Как получить токен администратора

Токен должен принадлежать **создателю или администратору** сообщества и иметь права на управление участниками.

### Вариант 1 — через vkhost.github.io (проще всего)

1. Откройте [vkhost.github.io](https://vkhost.github.io/)
2. Выберите приложение **«VK Admin»** или **«Kate Mobile»**
3. Разрешите доступ — обязательно отметьте права:
   - **`groups`** — управление сообществами (**обязательно**)
   - **`messages`** — если планируете добавлять фильтр «без диалога»
4. Скопируйте полученный `access_token`

### Вариант 2 — через Standalone-приложение

1. Создайте Standalone-приложение на [vk.com/apps?act=manage](https://vk.com/apps?act=manage)
2. В настройках приложения включите **«Прямой запрос к API»**
3. Сформируйте ссылку авторизации:

   ```
   https://oauth.vk.com/authorize?client_id=ВАШ_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=groups&response_type=token&v=5.131
   ```

4. Перейдите по ней, разрешите доступ — токен будет в адресной строке после `access_token=`

> 🔒 **Никогда не публикуйте токен** и не передавайте его третьим лицам. Токен = полный доступ к управлению вашим сообществом.

## 🆔 Как узнать ID сообщества

1. Откройте главную страницу сообщества
2. Нажмите **«Управление»** → вкладка **«Настройки»** (или **«Основная информация»**)
3. Найдите поле **ID** — это число, например `123456789`
4. Введите **только цифры**, без минуса и без префиксов `club`/`public`

Альтернативно: откройте раздел «Участники» и посмотрите на адресную строку — там будет `vk.com/club123456789`.

## 📖 Как пользоваться

| Поле | Описание |
|------|----------|
| **Токен** | `access_token` администратора сообщества |
| **ID сообщества** | Числовой ID (только цифры) |
| **Лимит за запуск** | Сколько участников удалить в этой сессии (1–1000) |
| **Задержка** | Пауза между запросами к API в миллисекундах (рекомендуется 200 мс) |
| **Тестовый режим** | Показывает, кого бы удалил, без реального удаления |

**Рекомендуемый порядок работы:**

1. Поставьте галочку **«Тестовый режим»** → «Запустить»
2. Проверьте лог: должны быть строки `Пропуск администратора: <id>` и `[ТЕСТ] Будет удалён: <id>`
3. Если всё корректно — снимите галочку → «Запустить» для реального удаления
4. Наблюдайте за логом, при необходимости нажмите «Остановить»

## ⚠️ Ограничения и предупреждения

- **Суточный лимит удалений.** По действующим правилам VK администратор/владелец может удалить до **1000 участников в сутки**, модератор — до **100**. При превышении API вернёт ошибку `code 29`, скрипт остановится.
  > 💡 В отдельных случаях пользователи сообщают об успешном удалении большего числа за сутки — лимиты могут меняться со стороны VK. Скрипт в любом случае корректно обработает ошибку и остановится.
- **Необратимость.** Удаление участника нельзя отменить средствами скрипта. Вернуть пользователей можно только через поддержку VK.
- **Риск ограничений аккаунта.** При слишком агрессивных настройках (маленькая задержка, много запусков подряд) VK может временно ограничить аккаунт. Рекомендуемая задержка — **200 мс и больше**.
- **Права токена.** Токен без scope `groups` или от имени обычного участника вызовет ошибку `code 15` (Access denied).
- **Администраторы не удаляются.** Скрипт получает список управляющих через `groups.getMembers?filter=managers` и пропускает их.

## 🐛 Известные проблемы

| Симптом | Причина | Решение |
|---------|---------|---------|
| `Ошибка получения участников: code 15` | Токен не администратор или без scope `groups` | Перегенерируйте токен с правами `groups` |
| `Достигнут лимит запросов (code 29)` | Исчерпан суточный лимит | Подождите до следующего дня |
| `Ошибка удаления <id>: code 6` | Слишком много запросов в секунду | Увеличьте задержку (например, до 500 мс) |
| `cannot use 'dict' as a set element` | Старая версия кода | Обновитесь до текущей версии (в ней исправлено) |
| `pip не распознаётся` | Python не в PATH | Используйте `py -m pip` или добавьте Python в PATH |
